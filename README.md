# Telegram Post Bot — Генератор разборов акций

Бот принимает текст / PDF / DOCX (и позже Google Doc), анализирует акцию и выдаёт готовый пост в твоём стандарте с эмодзи под компанию.

## Быстрый старт

1. Создай бота у @BotFather и получи токен.
2. Скопируй `.env.example` → `.env` и заполни:
   ```
   BOT_TOKEN=...
   ADMIN_ID=твой_telegram_id
   ```
3. Установи зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Запусти:
   ```bash
   python bot.py
   ```

## Как пользоваться

- Отправь боту текст акции или файл (PDF/DOCX)
- Напиши `/post`
- Получишь готовый пост с форматированием и эмодзи
